# 🏧 ATM Interface – Java Internship Task

This project simulates a simple ATM (Automated Teller Machine) using Java’s object-oriented programming principles. The console-based interface allows users to interact with their virtual bank account — checking balance, depositing money, and withdrawing funds with basic validations and interactive feedback.

## ✨ Features

- ✅ View current account balance  
- 💰 Deposit funds with positive amount validation  
- 💸 Withdraw funds with balance check  
- 🔁 Menu-driven loop for multiple transactions  
- 🔄 Real-time balance updates  
- 🧠 Modular design using classes for clear structure

## 🧱 Class Structure

| Class        | Responsibility |
|--------------|----------------|
| `BankAccount` | Manages account balance and handles deposit, withdrawal, balance checks |
| `ATM`         | Acts as user interface, presents options, handles input/output |
| `Main`        | Initializes account and launches ATM functionality |

## 🛠 Technologies Used

- Language: **Java**
- Concepts: Classes, Objects, Methods, Loops, Conditionals, Scanner Input
