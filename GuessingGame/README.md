# 🎯 Number Guessing Game

This is a simple command-line game where the player attempts to guess a randomly generated number within a given range. The game provides interactive feedback, limits attempts, supports multiple rounds, and keeps track of the score — all designed to sharpen logic and provide a fun challenge!

## 🚀 Features

- 🔢 Generates a random number between 1 and 100
- 💬 Provides feedback: "Too high", "Too low", or "Correct!"
- ⏳ Configurable attempt limit
- 🔁 Option to play multiple rounds
- 🏆 Scoring system based on performance
- 🧠 Clean and functional programming approach

## 🛠 Technologies Used

- Language: Java
- Core concepts: Loops, conditionals, user input handling, functions
